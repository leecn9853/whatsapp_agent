# 情商与人际沟通技能

## 核心立场（写之前必读）

- 高情商 ≠ 一味忍让、讨好、和稀泥。真正的高情商是：看清局势、守住边界、该软则软，该硬则硬。
- 反对"教条式老好人"套话。不要不加分辨地写"退一步海阔天空""吃亏是福""以德报怨"之类的话，除非确实适合该场景；大多数被冒犯/被侵权的场景里，这类话是要被明确否定的。
- 引用孔孟要准确，不能编造古籍原文：
  - 《论语·宪问》"以直报怨，以德报德"——孔子明确反对无原则的"以德报怨"，主张对伤害你的人要用"直"（正直、对等、不委曲）去回应，不是无底线宽恕。
  - 《孟子·滕文公下》"富贵不能淫，贫贱不能移，威武不能屈"——讲气节和边界，遇强权/胁迫不能屈服。
  - 《论语·卫灵公》"己所不欲，勿施于人"——用于点出双方视角，不是用来要求受害者单方面隐忍。
  - 如果想引用其他语录但不能确认原文准确，改用"传统智慧认为……"这类模糊表述，不要杜撰古籍原文。

## 强硬回击的边界（重要护栏）

- "该出手就出手"指的是**言语上/行动上的坚定维权**：明确拒绝、当场指出问题、说明后果、诉诸规则/制度/法律/上级/平台举报，而不是人身暴力。可以写"态度强硬""正面硬碰硬""必要时翻脸""不惯着"，但不能写鼓励肢体冲突、教人伤害他人身体的内容。
- 遇到侵犯权益或人身安全威胁时，正确的"硬"是：留证据、找第三方（HR/老师/警察/平台客服）、当面明确警告并说明后果，而不是以暴制暴。

## 场景库

生成前先判断落在哪个场景（可能跨场景）：

- **职场**：抢功、甩锅、PUA、越界差遣、办公室政治、跨部门推诺、职场冷暴力、被压榨加班
- **日常生活**：邻里矛盾、家庭关系（伴侣/父母/子女）、朋友借钱不还、边界感被侵犯、被pua式情感操控
- **校园**：同学冲突、师生关系、恋爱与友情、被起外号/排挤、小团体霸凌
- **节日/人情**：催婚催生、酒桌文化被强迫劝酒、随礼攀比、长辈说教、被"七大姑八大姨"式盘问

## 内容结构模板

1. **场景速写**：一两句话点出典型情境，让读者一秒对上号。
2. **低情商 vs 高情商对照**：
   - 低情商反应要覆盖两种反模式——(a) 压抑讨好型（忍气吞声、一味说好话）(b) 情绪化对抗型（直接爆发、人身攻击），说明二者本质都是失控，高情商不是简单等于"不发火"。
   - 高情商反应：给出可以直接照抄的具体话术，体现"温和而坚定"——礼貌但寸步不让。
3. **双方视角**：
   - 对方为什么这么说/做——常见心理动机（试探边界、习惯性甩锅、缺乏共情、单纯没意识到问题等）。
   - 你该有的思维方式——先判断对方动机再选策略，不是所有冲突都要升级，也不是所有冲突都该退让。
4. **国学依据**：引用1-2句准确的孔孟语录 + 一句白话解读，说明"经典不是让你当软柿子"。
5. **分寸提示**：什么情况可以退一步，什么情况必须硬气到底（参考上面的"强硬回击边界"）。

## 覆盖人群与语气调节

同一场景要能适配不同年龄/身份的读者，调节措辞但不改变原则：

- 学生/年轻人：更口语化，举例贴近校园/职场新人处境
- 职场中生代：更强调策略性、职业形象
- 涉及长辈的场景：把"如何面对长辈"和"作为长辈该反思什么"两种视角都给出，不单方面站队年轻人一方

- 控制在几百字以内、分段清晰，可适度用 emoji 点缀，避免写成大段说教
