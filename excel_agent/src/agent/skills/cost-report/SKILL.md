# 成本报表图片生成技能

## 核心流程

这不是通用 Excel 处理任务——数据来源（固定的两个接口）、模板结构都是写死的，不需要先用
`inspect_excel` 看结构。直接调用 `generate_cost_report_image` 工具即可：它会自己拉取最新数据、
套用模板、用 LibreOffice 重算汇总公式、把「成本分析看板」/「成本图表」sheet **整体**原样
截图成一张图片（月度趋势/部门预算/采购类别 3 个维度都在同一张图里，不拆开），生成的 PNG
会自动发给用户，不需要额外调用 `save_file`。**不会**生成或发送 Excel 文件。图片里看到的排版、
配色都是 Excel/LibreOffice 原生的，不是重新画的。

工具只有一个参数：

- `render_type`：图片形式，默认 `chart`（模板「成本图表」sheet 整体截图，一张图里包含
  月度趋势/部门预算/采购类别 3 个原生 Excel 图表）；用户明确要"表格""明细数据""合计"之类
  具体数字时才传 `table`（「成本分析看板」sheet 整体截图，3 个维度各自的表格+合计/平均行
  都在一张图里）。两种形式都不支持只截某一个维度——如果用户明确只要某一个维度，先按现有
  默认值处理，告诉用户目前只能整体截图。

不需要自己判断具体行列范围、也不需要多次调用做数据聚合——一次调用就能完成整个任务。如果同一次
任务里用户既要表格又要图表，需要分别以 `render_type=table` 和 `render_type=chart` 各调用一次；
工具内部会自动让同一个任务共享同一份已拉取/重算好的数据，不会重复拉取，两次调用看到的数字保证
一致。

## 常见请求 → 参数映射

- "生成成本报表" / "看下最新成本情况" / "把成本数据画个图表给我" → `render_type=chart`（默认值）。
- "月度成本明细/合计数据" / "各部门预算执行得怎么样" / "采购类别成本对比" → 要具体数字/合计才用
  `render_type=table`；只是想看看情况，默认 `render_type=chart` 即可（会看到全部 3 个维度的
  图表）。

## 关于失败情况

如果第三方数据服务没启动或 LibreOffice（`soffice`）不可用，工具会返回一段中文错误说明——
直接把这段说明转述给用户即可，不要自己猜测原因或编造替代数据。
