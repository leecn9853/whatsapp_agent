# 成本报表图片生成技能

## 核心流程

这不是通用 Excel 处理任务——数据来源（固定的两个接口）、模板结构都是写死的，不需要先用
`inspect_excel` 看结构。用 `execute` 工具跑本技能自带的 CLI 脚本即可：它会自己拉取最新数据、
套用模板、用 LibreOffice 重算汇总公式、把「成本分析看板」/「成本图表」sheet **整体**原样
截图成一张图片（月度趋势/部门预算/采购类别 3 个维度都在同一张图里，不拆开）。**不会**生成或
发送 Excel 文件。图片里看到的排版、配色都是 Excel/LibreOffice 原生的，不是重新画的。

## 怎么调用

```
python3 /workspace/skills/cost-report/scripts/generate.py \
  --render-type=chart --report-id=<report_id> --caller=<caller> --user-id=<user_id>
```

- `--render-type`：`chart`（默认，模板「成本图表」sheet 整体截图，一张图里包含月度趋势/
  部门预算/采购类别 3 个原生 Excel 图表）或 `table`（用户明确要"表格""明细数据""合计"之类
  具体数字时才传，「成本分析看板」sheet 整体截图，3 个维度各自的表格+合计/平均行都在一张图
  里）。两种形式都不支持只截某一个维度——如果用户明确只要某一个维度，先按默认值处理，告诉
  用户目前只能整体截图。
- `--report-id`：必填，用当前对话上下文里的 report_id（系统提示里的"当前任务 report_id"）。
- `--caller`/`--user-id`：可选，用当前对话上下文里的 caller/user_id（系统提示里能看到），
  没有就不传。

不需要自己判断具体行列范围、也不需要多次调用做数据聚合——一次调用就能完成整个任务。如果同一次
任务里用户既要表格又要图表，需要分别以 `--render-type=table` 和 `--render-type=chart` 各跑
一次脚本；只要 `--report-id` 相同，脚本内部会自动共享同一份已拉取/重算好的数据，不会重复拉取，
两次调用看到的数字保证一致。

**输出契约**：`execute` 返回后看最后一行 stdout：
- `RESULT_PATH:<路径>` → 把该路径原样传给 `save_file` 工具的 `source_path` 参数，图片就会
  发给用户，不需要额外传 `filename`/`content`。**不要**再用 `read_file` 去预览这个路径——
  图片已经通过 `save_file` 发给用户了，预览没有必要。
- `ERROR:<说明>` → 把说明转述给用户，不要猜测原因、不要重试。

## 常见请求 → 参数映射

- "生成成本报表" / "看下最新成本情况" / "把成本数据画个图表给我" → `--render-type=chart`（默认值）。
- "月度成本明细/合计数据" / "各部门预算执行得怎么样" / "采购类别成本对比" → 要具体数字/合计才用
  `--render-type=table`；只是想看看情况，默认 `--render-type=chart` 即可（会看到全部 3 个维度的
  图表）。

## 关于失败情况

如果第三方数据服务没启动或 LibreOffice（`soffice`）不可用，脚本 stdout 最后一行会是
`ERROR:<中文说明>`——直接把这段说明转述给用户即可，不要自己猜测原因或编造替代数据。
