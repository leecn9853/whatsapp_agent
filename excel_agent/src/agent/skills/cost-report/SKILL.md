# 成本报表生成技能

## 核心流程

这不是通用 Excel 处理任务——数据来源（固定的两个接口）、模板结构、单元格坐标都是写死的，不需要
先用 `inspect_excel` 看结构，也不需要自己拼列名/顺序。直接调用 `generate_cost_report` 工具即可：
它会自己拉取最新数据、套用模板、写入两张原始明细 sheet（「月度成本明细」「供应商采购成本」），
生成的文件会自动发给用户，不需要额外调用 `save_file`。

工具不需要任何参数，一次调用就能完成整个任务；不要试图自己分步骤读取接口数据再手动写入 Excel。

## 重要限制：不要编造汇总数字

模板里「分类整理」「成本分析看板」两个 sheet 是公式联动出来的（去重、`SUMIF`/`COUNTIFS` 汇总）。
`generate_cost_report` 只更新原始数据，不会在服务器侧重新计算这些公式——公式的值要等用户用真实
Excel/WPS 打开文件时才会自动算出来。所以：

- 回复里**不要**报告任何具体的汇总数字（总支出、预算执行率、超支占比等），因为服务器侧根本看不到
  这些公式算出来的值，编出来的数字一定是错的或过时的。
- 只需要说明报表已经用最新数据更新好了，用户打开文件就能看到最新的汇总看板。
- 如果之后想用 `inspect_excel` 去看这份文件，「成本分析看板」「分类整理」两个 sheet 的公式单元格
  读出来会是空的——这是预期行为，不是工具出 bug 了。

## 如果用户还想要图表

`generate_cost_report` 产出的文件里有一个空的「成本图表」sheet 留着，但**不要**直接对「成本分析
看板」sheet 用 `create_chart_sheet`/`aggregate_excel_sheet`——那张 sheet 的公式值服务器侧读不到
（见上面的限制），基于它聚合/画图会拿到空数据。

正确做法：改用同一份文件里的原始明细 sheet 出图，走现成的 `excel-chart` 技能——按月份/部门/成本
类别聚合「月度成本明细」，或按采购类别/付款状态聚合「供应商采购成本」，再画图。`filename` 参数
传 `generate_cost_report` 返回信息里报告的文件名，这样会在同一份输出文件上继续操作。
