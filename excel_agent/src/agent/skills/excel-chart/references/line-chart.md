# 折线图（`chart_type: "line"`）

## 适用场景

- 展示某个指标随时间的变化趋势：月度/季度/年度营收、成本、用户数等。
- 用户关心的是"趋势""增长/下降""拐点"，而不是某个时间点上不同类别谁大谁小
  （类别对比用 [bar-chart.md](bar-chart.md)）。
- 想在同一张图上对比多条指标随时间的走势（比如营收 vs 成本），可以给
  `value_columns` 传多个列，每个列会画成一条独立的折线。

## 数据要求

- `category_column` 必须是时间/顺序性质的列（月份、季度、日期、周次等），且该列
  在 sheet 里**已经按时间先后排好行序**——`create_chart_sheet` 只是按行顺序取数画图，
  不会自动排序。如果原始数据是乱序的（比如按地区分组、月份交叉），必须先用
  `aggregate_excel_sheet` 按时间列聚合，聚合结果会是干净的、按分组键顺序排列的表。
- `value_columns`：一个或多个数值列。多条线时注意量级是否可比——营收（百万级）和
  增长率（百分比）不要画在同一张折线图上，量级差太多时一条线会被压成直线，看不出变化。

## 何时需要先聚合

- 原始数据是逐日/逐单明细，用户想看的是月度或季度趋势 → 先用 `aggregate_excel_sheet`
  按目标时间粒度（月/季度）分组，`aggregations` 用 `"sum"`（累计值，如营收总额）或
  `"mean"`（均值，如客单价）。
- 数据本来就已经是"一个时间点一行"的干净时间序列（比如已有的"月度汇总"sheet）→
  可以跳过聚合，直接对它画图。

## 参数示例

假设已有一张按月聚合好的 sheet「月度汇总」，表头为 `月份 / 营收 / 成本`：

```
create_chart_sheet(
    filename=<上一步返回的文件名>,
    sheet_name="月度汇总",
    chart_type="line",
    category_column="月份",
    value_columns=["营收", "成本"],
    title="2025 年各月营收与成本趋势",
    new_sheet_name="营收成本趋势图",
)
```

## 常见错误

- `category_column` 传了一个分类列（比如"部门"）而不是时间列——折线图默认类别间
  有顺序关系，分类数据用折线图会画出一条毫无意义的"连线"，应该改用柱状图。
- 时间跨度很长（比如两年的逐日数据）没有先聚合，导致横轴挤满几百个刻度、完全看不清——
  应先聚合到月/季度粒度。
- 多条线之间量级差异悬殊，压扁了变化趋势。

## 检查清单

- [ ] `category_column` 是时间/顺序列，且行序已经是时间先后顺序
- [ ] 数据粒度适合趋势阅读（不是几百个时间点堆在一起）
- [ ] 多条线之间量级可比，或已经分成多张图
