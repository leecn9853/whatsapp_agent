# 柱状图（`chart_type: "bar"`）

## 适用场景

- 不同类别之间的数值对比：部门/产品线/地区/团队的排名或横向对比。
- 离散时间点之间的对比（比如"近 5 年营收对比"这种类别数不多、更关心逐年数值
  差异而非连续趋势的场景）；如果类别数多、更关心变化走势，改用
  [line-chart.md](line-chart.md)。
- 是默认的"安全选择"：当类别数偏多（超过饼图适用的 ≤6 个）导致不适合用饼图时，
  应该改用柱状图而不是硬塞进饼图。

## 数据要求

- `category_column`：分类列（部门名、产品线名、地区名等），或类别数不多的离散
  时间列（年度）。
- `value_columns`：一个或多个数值列。多个列时会画成分组柱状图（每个类别下并排
  多根柱子），适合同时对比多个指标（比如各部门的营收和成本）。

## 聚合建议

- 类别数很多（比如原始明细里有几十个客户/SKU）时，柱状图会因为柱子太密、标签
  重叠而不可读。优先做法：
  - 先聚合出 Top N（用户关心的最重要的几类），把剩余归为"其他"；或者
  - 换一个类别数更少的维度分组（比如按产品线而不是按单个 SKU）。
- 数据本身已经是"一个类别一行"的干净汇总表时，可以跳过聚合直接画图。

## 参数示例

假设已有一张按部门聚合好的 sheet「部门成本汇总」，表头为 `部门 / 成本 / 营收`：

```
create_chart_sheet(
    filename=<上一步返回的文件名>,
    sheet_name="部门成本汇总",
    chart_type="bar",
    category_column="部门",
    value_columns=["成本", "营收"],
    title="各部门成本与营收对比",
    new_sheet_name="部门对比图",
)
```

## 常见错误

- 类别数超过 15~20 个仍直接画图，柱子和标签挤成一团。
- 用户明确想看"占比"（各类别占整体的百分比）而不是"绝对值大小对比"时，柱状图
  不如饼图直观——但类别数 >6 时仍应优先用柱状图，可以在标题/回复里说明这是绝对值对比。
- 把时间序列的连续趋势画成柱状图（比如逐月数据超过 12 个点）——数据点较多的连续
  时间趋势更适合折线图。

## 检查清单

- [ ] 类别数在可读范围内（一般不超过 15~20 个，超出则先聚合成 Top N + 其他）
- [ ] 多个 `value_columns` 时确认它们量级可比，适合放在同一张图对比
- [ ] 标题说明清楚对比的是什么维度、什么指标
