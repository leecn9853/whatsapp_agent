# 饼图（`chart_type: "pie"`）

## 适用场景

- 展示单一指标在各类别之间的**占比构成**（各部分之和等于一个有意义的整体），
  比如"各产品线营收占总营收的比例""各渠道获客占比"。
- 只在类别数少（建议 ≤6）时使用。类别数更多时占比图会被切成很多细小的扇区，
  反而看不清楚，应改用 [bar-chart.md](bar-chart.md)。
- 如果用户想看的是"哪个类别数值最大/最小"这种排名对比，而不是"占整体的比例"，
  即使类别数少也优先考虑柱状图——排名对比用柱状图更容易读出数值差异。

## 数据要求

- `value_columns` 只能传恰好一个列（工具会直接拒绝多个值列的请求，因为一个
  饼图只能表示一个指标的构成）。
- 数值应为非负数——占比图对负数没有意义（比如"利润"里有部门亏损为负数时，
  不适合直接画饼图，需要先跟用户确认怎么处理，或改用柱状图对比正负值）。
- `category_column` 的类别数建议 ≤6；类别数在 6~10 之间时，优先考虑把长尾类别
  聚合成"其他"再画图，而不是直接把所有细类都塞进去。

## 何时需要先聚合

- 原始明细粒度太细（比如几十个 SKU 各自的销量）时，先用 `aggregate_excel_sheet`
  按用户关心的分类维度分组求和，得到类别数少的汇总表。
- 聚合后类别数仍然偏多（>6）时，可以进一步把占比最小的若干类别合并成"其他"这
  一类（如果 `aggregate_excel_sheet` 的分组维度支持这样处理；否则在回复里说明
  改用柱状图更合适，并直接用 `bar` 画图）。

## 参数示例

假设已有一张按产品线聚合好的 sheet「产品线营收汇总」，表头为 `产品线 / 营收`，
且产品线只有 4 个类别：

```
create_chart_sheet(
    filename=<上一步返回的文件名>,
    sheet_name="产品线营收汇总",
    chart_type="pie",
    category_column="产品线",
    value_columns=["营收"],
    title="各产品线营收占比",
    new_sheet_name="营收占比图",
)
```

## 常见错误

- 类别数超过 6 仍用饼图，画出一堆看不清标签的细小扇区。
- 传了多个 `value_columns`——工具会直接拒绝，需要拆成多张饼图或改用柱状图对比。
- 数据里包含负数（比如亏损的部门）却直接画饼图，扇区大小失去实际意义。
- 用饼图表达"随时间变化的趋势"——饼图只能表达某一时刻的构成快照，不适合趋势场景。

## 检查清单

- [ ] `value_columns` 只有一个列
- [ ] 类别数 ≤6（超出已聚合成"其他"或改用柱状图）
- [ ] 数值均为非负
- [ ] 标题说明了"什么指标的占比构成"
